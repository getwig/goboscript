# `std` is the goboscript standard library

## Installation

Add the following to your `goboscript.toml` file:

```toml
std = "2.1.0"
```

## Vendored copy

This directory is goboscript/std v2.1.0 (commit f5b1079, MIT, (c) 2025 aspizu), vendored into
this goboscript fork so builds can use it offline with `goboscript build --std-path std`.
Changes against v2.1.0 are listed in the git history of this directory.
